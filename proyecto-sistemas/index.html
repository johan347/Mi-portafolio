PROYECTO ACADÉMICO

Proyecto de Sistemas

Proyecto desarrollado durante mi formación académica, relacionado con sistemas, tecnología y administración de entornos virtuales.

Descripción del proyecto

Este proyecto representa una práctica académica relacionada con sistemas y tecnología. El objetivo fue aplicar conocimientos adquiridos durante mi formación en Ingeniería en Sistemas y trabajar con diferentes herramientas tecnológicas.

Áreas trabajadas

Durante el desarrollo del proyecto se trabajaron conceptos relacionados con sistemas, configuración, administración de entornos virtuales y tecnologías informáticas.

Tecnologías utilizadas

VirtualBox Windows Redes Sistemas
